# Alzheimer's & Parkinson's Disease Detection Using Deep Learning

## 📖 Project Overview

This project presents a deep learning approach for the automatic detection of Alzheimer's disease and Parkinson's disease using Convolutional Neural Networks (CNNs). The goal is to assist in the early diagnosis of these neurodegenerative diseases by analyzing MRI images and classifying them accurately.

The project was developed as part of my Master's degree in **Embedded Systems and Digital Services**.

---

## ✨ Features

- Automatic detection of Alzheimer's disease from MRI images.
- Automatic detection of Parkinson's disease from MRI images.
- Image preprocessing and normalization.
- CNN model training and evaluation.
- Prediction on new MRI images.
- Model performance visualization.
